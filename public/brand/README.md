# Marca

`eme-group-logo.png` es el **logo oficial** de em&e group (249 × 95 px, PNG
con transparencia), entregado con el encargo E01. La cabecera
(`src/layouts/AppHeader.tsx`) y el favicon (`index.html`) lo toman de aquí;
para cambiarlo basta con sustituir el fichero manteniendo el nombre.

El logo es oscuro sobre transparente: en la cabecera blanca (variante C, por
defecto) va directo, sin placa; en modo oscuro y en la variante A (cabecera
azul marino) la cabecera lo pone sobre una superficie clara (token
`--logo-surface` de `src/styles/globals.css`) para que siga siendo legible.
